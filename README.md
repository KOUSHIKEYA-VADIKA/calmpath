# 🌿 CalmPath

CalmPath is a full-stack web application designed to help users build healthier habits through daily self-reflection, mood tracking, and routine analysis. Instead of acting as a therapist or providing medical advice, CalmPath encourages users to understand their emotions, identify behavioral patterns, and improve their overall well-being through consistent habit tracking.

> **Disclaimer:** CalmPath is intended for self-awareness and personal growth. It does **not** diagnose mental health conditions or replace professional medical or psychological care.

# 🎯 Project Objective

Mental well-being is influenced by our daily habits, routines, and emotions. CalmPath helps users become more self-aware by allowing them to record their daily experiences and visualize patterns over time.

The goal is to encourage healthier routines, emotional awareness, and gradual self-improvement through data-driven insights.

# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/CalmPath.git
```

## 2. Navigate to the Project Directory

```bash
cd CalmPath
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Configure Environment Variables

Create a `.env` file in the root directory.

```env
MONGODB_URI=your_mongodb_connection_string
PORT=5000
```

## 5. Run the Application

```bash
npm start
